# Initialize-ASTRuleGenerator Module
## Description
PSScriptAnalyzer custom rule module that turns simple rules declared in a JSON file into AST checks, for example to detect malicious PowerShell.

## Initialize-ASTRuleGenerator Cmdlets
### [Measure-CustomASTRule](Measure-CustomASTRule.md)
Applies the rules declared in a JSON rules file to a script, as a PSScriptAnalyzer custom rule.
